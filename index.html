Calendar labels

P1 = highest-priority opportunity; P2 = strong/relevant; P3 = selective/opportunistic. Common tags include BD, OUTREACH, ELT, EDTECH and INTL SCHOOL.

Source & privacy standard

The public feed should contain only public event information and non-confidential Mirai Minds relevance notes. Internal sales notes, student data, pricing, private contacts and negotiations should remain outside this feed.
